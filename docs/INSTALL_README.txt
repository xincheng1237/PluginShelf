PluginShelf（插件架）1.1
macOS 14 或更新版本 · Apple 芯片 / Intel

安装：打开 DMG，将左侧 PluginShelf 拖入右侧“应用程序”文件夹。
如已安装旧版，请先退出 PluginShelf，再替换应用。

首次打开会扫描本机音频插件。搜索并多选后，可以批量备份或移到废纸篓。

1.1 使用系统废纸篓，不安装后台清理程序。
自动清理请在 Finder → 设置 → 高级中开启“30 天后移除废纸篓中的项目”。
此设置影响整个系统废纸篓；手动清空会提前永久删除，不保证保留满 30 天。

应用内“废纸篓”保留本应用的删除记录，可多选还原或经过两次确认后永久删除。
已被清理或移出的文件会标为不可用；磁盘未连接时，请重新连接后刷新。
旧版废纸篓项目仍可还原或手动永久删除，不再自动到期清理。

备份不包含独立音色库和许可证。本安装包使用本地签名，尚未 Apple 公证。
