PluginShelf（插件架）1.0
音频插件管理工具 · macOS 14 或更新版本 · Apple 芯片 / Intel

安装
1. 双击打开 PluginShelf-1.0-macOS-Universal.dmg。
2. 将左侧 PluginShelf 拖到右侧“应用程序”文件夹，等待复制完成。
3. 从“应用程序”打开 PluginShelf，首次启动会扫描本机音频插件。
如已安装旧版，请先退出应用，再替换。

基本使用
搜索名称、厂商或路径，或按格式、添加时间筛选插件。
按住 ⌘ 点选、Shift 连选，即可批量备份或移到废纸篓。
备份为 .pluginshelfbackup 文件夹，恢复时点击“从备份恢复”。
删除需两次确认；废纸篓默认保留 30 天，期间可还原，到期后会彻底删除。

说明
备份不包含独立音色库与许可证。此版本为本地签名，尚未通过 Apple 公证。
