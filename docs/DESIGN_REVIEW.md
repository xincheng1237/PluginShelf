# 设计与动画把关

本轮按 emil-design-eng 与 animate Skill 实施，自审与原生界面实测，未声称由独立设计师评审。

## 界面审查

| Before | After | Why |
| --- | --- | --- |
| 批量选择可能保留已隐藏项目 | 搜索、范围或筛选变化时清除选择，操作集合再次限定为当前结果 | 防止用户看不见的项目被删除 |
| 混合选中只读项目时可能只备份其中一部分 | 整组禁用操作，用户需明确移除只读项 | 避免选择数量和实际操作数量不同 |
| 单次弹窗不足以核对批量删除 | 完整路径清单，然后精确输入数量与勾选后果 | 让最终动作来自用户明确意图 |
| 可能把文件时间视为真实安装日期 | 标注文件系统时间，独立展示首次发现日期 | 信息可用且不过度承诺 |
| 空表格挤压窗口布局 | GeometryReader 明确窗口边界，Table 允许收缩 | 实测空废纸篓、切换列表、原生详情栏均保持可见 |
| 选中行次级文字对比不足 | 选中状态使用主文字样式 | 名称、格式、大小和日期保持可读 |
| 自定义悬浮按钮与非标准列表 | NavigationSplitView、Table、Toolbar、Settings、系统文件面板与 Sheet | 采用 macOS 现成焦点、键盘、滚动和多选行为 |

## 动画决策

搜索、排序、列表选择、首字母筛选：高频操作，即时变化，不加装饰动画。

两步确认页的鼠标推进：偶发状态变化，使用 SwiftUI opacity transition，0.20 秒，曲线 (0.23, 1, 0.32, 1)。键盘触发时不添加该过渡。“减少动态效果”开启时只保留 0.12 秒淡化，不移动位置，不缩放数据。

Sheet、原生 Inspector 和系统按钮使用系统行为，不叠加自定义弹跳、不加循环装饰。未引入网页动画库。

## 已目视检查

演示样本的列表、详情、批量检索、两步确认、错误数量禁用、批量移入废纸篓及还原。检查了空列表与窗口布局。截图 `interface-demo.png` 使用隔离样本，不是真实插件列表。

待正式版本补充：VoiceOver 实机完整路径、独立深色模式巡检、多种显示缩放、动画减速逐帧检查与跨 macOS 版本测试。

采用 apple-design、emil-design-eng 与 write-swift 进行实现者自检。用户随后提供的 changelog-icons-matched 包明确了 13 pt 常规字号和双层配色；应用直接使用原生 Label，不嵌入固定浅色 PNG。未新增装饰动画，不改日志内容或增加版本条目。

安装窗口限制：本轮测试窗口的“隐藏状态栏 / 路径栏”同时影响了 Finder 新窗口默认值，已通过原生菜单还原。恢复后读取 ShowStatusBar=1、ShowPathbar=1，并正常卸载、重新打开用户提供的 Ollama 和 The Unarchiver 原包，两者均出现状态栏、标签栏和路径栏。此前旧窗口与新窗口截图不具备同一偏好下的可比性。本机的 DMG 隐藏参数不能可靠覆盖这些 Finder 偏好；不为达到截图效果而保留全局偏好修改，也不加入启动脚本或额外安装程序。
