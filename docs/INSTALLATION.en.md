# Install PluginShelf 1.1

Requires macOS 14 or later; supports Apple silicon and Intel with one Universal 2 download.

1. Download the DMG from the [official Releases page](https://github.com/xincheng1237/PluginShelf/releases/latest).
2. Quit any previous version of PluginShelf.
3. Open the DMG and drag PluginShelf into Applications, replacing the old version if prompted.
4. Open PluginShelf from Applications. Eject the disk image when finished.

The current package is ad-hoc signed and is not notarized by Apple. If macOS blocks it, verify that it came from the official repository, then use the system’s app-specific “Open Anyway” option in System Settings → Privacy & Security. Do not disable Gatekeeper globally.

Settings and backup packages are retained when replacing the app. Items deleted with 1.0 remain accessible in the app’s legacy Trash; newly deleted files use the system Trash. Automatic removal depends on Finder’s optional 30-day setting.

Check for updates in the PluginShelf app menu or Settings → General. Downloaded updates are verified before the DMG opens; quit the running app before dragging the replacement into Applications.
