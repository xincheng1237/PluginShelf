## 核心测试

最终结果：arm64 **18/18 通过**，x86_64 经 Rosetta **18/18 通过**。

最终测试覆盖：七种独立格式、AUv3 只读发现、多条件筛选、备份与恢复内容一致、恢复不覆盖、损坏备份拒绝、30 天精确到期、只清理到期副本、路径穿越拒绝、目录链接逃逸拒绝、内部相对链接保留、外部链接拒绝、顶层链接与系统保护、未知原路径拒绝、重复清单拒绝、中断后恢复保护、权限失败保留原插件、排除非 AU 系统组件。

测试使用本轮创建的临时目录与文本 Bundle，不执行真实插件二进制。Swift Testing 输出见 `tests-arm64.log` 与 `tests-x86_64-rosetta.log`。Rosetta 测试验证 x86_64 核心逻辑，不等同于 Intel 实机完整 UI 验收。

## 界面实测

通过原生 macOS UI 自动化检查演示样本：

- 原生三栏列表与 Inspector、名称和路径信息可见。

- 交付 Release 应用已在本机正常打开并呈现真实插件扫描结果；没有对真实插件执行删除、还原或覆盖。

## 真实扫描

扫描标准目录及常用应用目录，不加载插件代码。最终计数见 `scan-audit-20261020.json`。系统组件按 `AudioComponents` 中 `au…` 类型筛选，避免将脚本组件和编解码器误识别为 AU。

扫描没有保证穷尽全部宿主专有格式。文件系统添加/创建时间不能证明准确安装时间。备份校验不包含许可证或外置库，也不是来源认证。
