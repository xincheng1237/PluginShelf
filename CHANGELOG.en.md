# Release Notes

## 1.1

### ✅ New Features

- Added system Trash support, with batch restore and permanent deletion in the app.
- Added update checks, both automatically at launch and on demand.
- Added Chinese and English interfaces with a language selector that follows the system by default.
- Added release notes to view changes in each version.

### ✨ Improvements

- Changed Trash cleanup so newly deleted plug-ins follow the system’s automatic removal setting.
- Improved Trash records and batch actions while retaining support for items deleted in the previous version.

## 1.0

### ✅ Features

- Supports audio plug-in scanning and management for AU, VST2, VST3, AAX and other common formats.
- Supports search, date filters, sorting and alphabet navigation.
- Supports batch backup and restore to the original installation locations.
- Supports batch deletion and Trash restore, with two-step confirmation before deletion.
- Supports plug-in categories, with automatic detection for supported plug-ins and manual categorization.
